# مكتبة الطالب الإسلامية

تطبيق ويب تقدمي (PWA) — مكتبة إسلامية منظمة لطلب العلم.

## الأقسام
- **القرآن الكريم**: برواية حفص عن عاصم (رسم عثماني) مع التفسير الميسّر وشرح مبسّط باللهجة الخليجية (زر تبديل)
- **التجويد**: أحكام النون والميم الساكنة، المدود، القلقلة، الراء، مخارج الحروف
- **الأصول الثلاثة** و**القواعد الأربع** — للإمام محمد بن عبد الوهاب
- **مختصر كتاب التوحيد** — أقسام التوحيد وأنواع الشرك
- **السيرة النبوية** — حياته ﷺ وأخلاقه ومأكولاته
- **أدلة وجود الله** — لدفع شبهات الملحدين
- **الاختبارات** — 70 سؤالاً في كل الأقسام مع حفظ أفضل نتيجة

## مصادر البيانات
- نص القرآن (حفص): fawazahmed0/quran-api عبر jsDelivr
- التفسير الميسّر: quran.com API v4 (مورد 16)

## التشغيل محلياً
افتح `index.html` في المتصفح، أو: `python3 -m http.server` ثم زر `http://localhost:8000`

## النشر
يُستضاف كملفات ثابتة (static) — مثلاً على PythonAnywhere.
